# noin9

اسکرپ خودکار آخرین پیام‌های چند کانال **پابلیک** تلگرام، بدون نیاز به بات یا اکانت شخصی.
هر ۵ دقیقه از طریق GitHub Actions اجرا می‌شه.

## چطور کار می‌کنه؟

از صفحه‌ی پیش‌نمایش عمومی هر کانال (`https://t.me/s/<channel>`) استفاده می‌کنه —
همون صفحه‌ای که بدون لاگین و بدون اپ تلگرام هم توی مرورگر قابل دیدنه.
به همین خاطر فقط برای **کانال‌های پابلیک** جواب می‌ده (نه گروه، نه کانال خصوصی).

هر پیام بررسی می‌شه: اگه خطی توش با یکی از این پیشوندها شروع بشه، «کانفیگ» حساب می‌شه
و کل اون پیام از فایل متنی عادی حذف و به پوشه‌ی `config/` منتقل می‌شه:

```
vmess://  vless://  trojan://  ss://  shadowsocks://
wg://  wireguard://  warp://  reality://
```

## خروجی

- **`media/<channel>.txt`** — فقط ۲۰ پیام متنی عادی آخر هر کانال (غیر از کانفیگ‌ها).
  هر بار کامل بازنویسی می‌شه، پس همیشه فقط ۲۰ تای آخر توشه.

- **`config/Sub1.txt`, `Sub2.txt`, ...** — همه‌ی خط‌های کانفیگ پیدا شده، از همه‌ی کانال‌ها،
  توی یک مجموعه‌ی مشترک. **هیچ‌وقت پاک نمی‌شن**، فقط اضافه می‌شن. تکراری‌ها حذف می‌شن
  (یه کانفیگ که قبلاً ذخیره شده، دوباره نوشته نمی‌شه). وقتی یه فایل به ۶۰۰ خط برسه،
  خط‌های جدید توی فایل بعدی (`Sub2.txt`، بعد `Sub3.txt` و ...) نوشته می‌شن.
  این فایل‌ها می‌تونن مستقیم به‌عنوان لینک Subscription توی اپ‌های V2ray/Clash استفاده بشن.

## راه‌اندازی

1. این پوشه رو توی یک ریپوی گیت‌هاب جدید (یا موجود) قرار بده و پوش کن.
2. توی فایل `channels.txt`، یوزرنیم کانال‌های موردنظر رو یکی زیر یکی بنویس (بدون یا با `@`، فرقی نداره).
3. مطمئن شو `Settings > Actions > General > Workflow permissions` روی
   **"Read and write permissions"** تنظیم شده باشه (برای اینکه اکشن بتونه commit/push کنه).
4. از تب **Actions > noin9 - Update Telegram Channels > Run workflow** اولین اجرا رو دستی تست کن،
   بعدش خودش هر ۵ دقیقه اجرا می‌شه.

## محدودیت‌ها (مهم)

- فقط **کانال‌های پابلیک** پشتیبانی می‌شن.
- هر بار فقط آخرین ~۲۰ پیام قابل‌مشاهده‌ی صفحه‌ی پیش‌نمایش بررسی می‌شه؛ اگه یه کانال بین دو اجرا
  (۵ دقیقه) بیشتر از ۲۰ پیام جدید بفرسته، بعضی پیام‌ها ممکنه از قلم بیفتن.
- زمان‌بندی cron توی GitHub Actions تضمین‌شده‌ی دقیق نیست؛ ممکنه چند دقیقه تاخیر بیفته.
