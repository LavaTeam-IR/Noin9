# noin9

اسکرپ خودکار آخرین پیام‌ها و فایل‌های چند کانال **پابلیک** تلگرام، بدون نیاز به بات یا اکانت شخصی.
هر ۵ دقیقه از طریق GitHub Actions اجرا می‌شه.

## چطور کار می‌کنه؟

از صفحه‌ی پیش‌نمایش عمومی هر کانال (`https://t.me/s/<channel>`) استفاده می‌کنه —
همون صفحه‌ای که بدون لاگین و بدون اپ تلگرام هم توی مرورگر قابل دیدنه.
به همین خاطر فقط برای **کانال‌های پابلیک** جواب می‌ده (نه گروه، نه کانال خصوصی).

## خروجی

- برای هر کانال یک فایل `<channel>.txt` توی ریشه‌ی ریپو، شامل ۲۰ پیام متنی آخر
  (هر بار کامل بازنویسی می‌شه، پس همیشه فقط ۲۰ تای آخر توشه).
- برای هر کانال یک پوشه `media/<channel>/` با فایل‌های مدیای ۲۰ پیام آخر
  (عکس، ویدیوی کوچیک، فایل ضمیمه). فایل‌های مربوط به پیام‌های خارج‌شده از بازه‌ی ۲۰ تایی
  خودکار پاک می‌شن.

## راه‌اندازی

1. این پوشه رو توی یک ریپوی گیت‌هاب جدید (یا موجود) قرار بده و پوش کن.
2. توی فایل `channels.txt`، یوزرنیم کانال‌های موردنظر رو یکی زیر یکی بنویس (بدون یا با `@`، فرقی نداره).
3. مطمئن شو ریپو **Public** یا **Private با Actions فعال** هست و توی تنظیمات ریپو:
   `Settings > Actions > General > Workflow permissions` روی
   **"Read and write permissions"** تنظیم شده باشه (برای اینکه اکشن بتونه commit/push کنه).
4. تمام. اولین اجرا رو می‌تونی از تب **Actions > Update Telegram Channels > Run workflow**
   دستی تست کنی، بعدش خودش هر ۵ دقیقه اجرا می‌شه.

## محدودیت‌ها (مهم)

- فقط **کانال‌های پابلیک** پشتیبانی می‌شن.
- ویدیوهای بزرگ و بعضی فایل‌ها ممکنه توی صفحه‌ی پیش‌نمایش لینک مستقیم نداشته باشن
  و دانلود نشن (این یک محدودیت خود صفحه‌ی `t.me/s/` هست، نه اسکریپت).
- زمان‌بندی cron توی GitHub Actions تضمین‌شده‌ی دقیق نیست؛ ممکنه چند دقیقه تاخیر بیفته
  (خصوصاً روی ریپوهای رایگان/شلوغ).
- اجرای مکرر هر ۵ دقیقه روی حساب‌های رایگان گیت‌هاب مصرف دقیقه‌ی Actions داره؛ اگه ریپو
  Private باشه، سهمیه‌ی ماهانه محدوده.

## تست محلی
