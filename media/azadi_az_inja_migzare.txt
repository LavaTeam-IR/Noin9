## 🧪 مواردی که باید تست شوند

این نسخه یک آپدیت بزرگ است. ForgeCore حالا با CoreForge 1.0 (113) هماهنگ شده است.

- 🔐 Private Configs — کانفیگ‌های خصوصی 
  یک بخش قفل‌شده در بالای صفحه‌ی Configs اضافه شده که به‌صورت خودکار و مخصوص دستگاه شما پر می‌شود؛ بدون نیاز به ثبت‌نام یا وارد کردن کد.

  کانفیگ‌ها فقط با نام‌هایی مثل Private N همراه با نوع پروتکل نمایش داده می‌شوند. هنگام اتصال، IP خروجی و موقعیت آن‌ها نیز نمایش داده می‌شود.

  لطفاً بررسی کنید که:
  - این بخش به‌درستی پر شود؛
  - کانفیگ‌ها متصل شوند؛
  - امکان Export، Copy، Share یا Edit کردن آن‌ها وجود نداشته باشد.

- 🛡️ Kill Switch 
  مسیر: Settings → VPN  
  وقتی فعال باشد، هیچ ترافیکی خارج از VPN از گوشی خارج نمی‌شود؛ حتی زمانی که VPN در حال اتصال مجدد است.

- 🌍 Country & Speed Check 
  برای هر کانفیگ، کشور خروجی با پرچم نمایش داده می‌شود و سرعت Download/Upload نیز به‌صورت ↓/↑ Mbps نشان داده خواهد شد.

- 🧹 حذف کانفیگ‌های خراب بعد از تست 
  امکان حذف خودکار موارد زیر وجود دارد:
  - کانفیگ‌های Timeout شده؛
  - کانفیگ‌های Dead؛
  - یا هر دو.

- ⚡ Auto Test 
  کانفیگ انتخاب‌شده هنگام اجرای برنامه و همچنین هنگام انتخاب آن به‌صورت خودکار تست می‌شود.

  در صورت تمایل می‌توانید تست دوره‌ای را روی یکی از این زمان‌ها قرار دهید:
  - هر ۳۰ ثانیه
  - هر ۱ دقیقه
  - هر ۵ دقیقه

- 🧭 Routing
  - امکان ویرایش Ruleهای موجود؛
  - کلید روشن/خاموش برای Routing؛
  - تنظیمات **Simple / Advanced**؛
  - گزینه‌ی I'm in Iran 🇮🇷.

  این حالت دیگر Google، YouTube، Apple یا GitHub را Block نمی‌کند.

- 📂 Configs
  - گزینه‌ی Move to Group از همان بار اول باید درست کار کند؛
  - هنگام Import می‌توانید پوشه‌ی مقصد را انتخاب کنید؛
  - برای Subscriptionهای بزرگ فیلترهای جدید اضافه شده:
    - First N
    - Random N
    - Protocol
    - Country
  - برای هر Config، Folder و Subscription امکان ساخت QR Code وجود دارد؛
  - ابزار Text-to-QR نیز اضافه شده است.

- 🔗 Auto Chain 
  فقط Exit را انتخاب کنید؛ Entry به‌صورت خودکار پیدا می‌شود. اگر Entry از کار بیفتد، سیستم به Entry دیگری Failover می‌کند.

- 🌐 SlipNet / dnstt Configs 
  پشتیبانی از DNSTT و NoizDNS از طریق:
  - UDP
  - DoH
  - DoT

- ☁️ WARP
  - Endpoint Scanner بهتر شده است؛
  - ثبت‌نام WARP حالا روی شبکه‌هایی که Sign-up را Block می‌کنند نیز کار می‌کند؛
  - Tailscale و WARP در صفحه‌ی Home فقط اطلاعات مربوط به خودشان را نشان می‌دهند؛
  - IP خروجی واقعی آن‌ها نیز نمایش داده می‌شود.

- 🧩 Compatibility — سازگاری بیشتر
  - REALITY روی **Xray 26.9.8 و نسخه‌های جدیدتر**؛
  - Certificate Pinهای `pcs=`؛
  - **Hysteria2 Gecko Obfuscation**؛
  - گزینه‌های جدیدتر **XHTTP**؛
  - کلیدهای vpn:// مربوط به AmneziaVPN و **3x-ui**؛
  - پشتیبانی از OpenVPN tls-crypt-v2.

🐞 در صورت مشاهده‌ی هرگونه مشکل، لطفاً نوع کانفیگ و نوع شبکه‌ی خود را گزارش کنید؛ مثلاً Wi-Fi یا دیتای موبایل و نام اپراتور.

# 🚀 آپدیت CoreForge 1.0 — iOS و macOS

## 🧪 موارد جدید این نسخه

### 🔐 Private Configs
- کانفیگ‌های Private حالا به‌جای Private 1`، `Private 2 و... اسم واقعی خودشان را نشان می‌دهند.
- آدرس سرور همچنان مخفی می‌ماند و نمایش داده نمی‌شود.
- اگر اسم یک کانفیگ باعث لو رفتن اطلاعات سرور شود، آن کانفیگ همچنان با نام Private N نمایش داده می‌شود.

### 📱 بهبود نمایش روی آیفون‌های کوچک
روی iPhone SE**، مدل‌های **mini و در حالت Display Zoom:

- نام تب‌های پایین حالا کامل نمایش داده می‌شود:
  - Configs
  - Settings
- دیگر به‌صورت Confi… یا Setti… بریده نمی‌شوند.
- Subscription یا Folder بازشده هم داخل Card خودش می‌ماند و از کادر بیرون نمی‌زند.

### 🌐 OpenVPN
- پروفایل‌هایی که گواهی (Certificate) سرورشان برای Server Usage مشخص نشده، حالا می‌توانند متصل شوند.
- قبلاً این نوع پروفایل‌ها با Certificate Error رد می‌شدند.
- گواهی‌هایی که توسط Certificate Authority ناشناس صادر شده باشند، همچنان رد می‌شوند.

## ✅ لطفاً این موارد را تست کنید

- 🔐 Private Configs 
  بررسی کنید که:
  - اسم کانفیگ‌ها نمایش داده شود؛
  - آدرس‌ها هیچ‌وقت نمایش داده نشوند.

- 🌐 OpenVPN 
  یک پروفایل OpenVPN را تست کنید که قبلاً با Certificate Error وصل نمی‌شد.

- 📱 صفحه Configs 
  صفحه Configs را روی یک آیفون کوچک یا در حالت Display Zoom بررسی کنید.
