📱 WebToApp
تبدیل سایت به اپ اندروید، مستقیم با گوشی!

اگه همیشه برات سؤال بوده چطور میشه یک سایت یا پروژه وب رو بدون کامپیوتر به یک اپ اندرویدی تبدیل کرد، WebToApp یکی از ابزارهای جالب برای این کاره.

🔓 متن‌باز (Open Source) و سورس پروژه در GitHub منتشر شده.

🔹 تبدیل سایت و پروژه‌های HTML به APK
🔹 🛑 فیلتر تبلیغات و پشتیبانی از AdBlock
🔹 🌐 پشتیبانی از Proxy و تنظیمات شبکه
🔹 🔐 تنظیمات DNS و DoH
🔹 🎨 شخصی‌سازی نام، آیکون و Splash Screen
🔹 📦 خروجی APK و AAB
🔹 🧩 پشتیبانی از پروژه‌های چندسایته
🔹 ⚙️ پشتیبانی از JavaScript و قابلیت‌های پیشرفته وب
🔹 📱 ساخت پروژه مستقیماً روی اندروید، بدون نیاز به PC
﻿
🆕 نسخه 2.7.5 قابلیت‌های جدیدی مثل پشتیبانی اختیاری از Node.js، PHP، Python، Go و WordPress و امکانات جدید مدیریت پروژه را اضافه کرده.
