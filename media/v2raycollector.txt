📱🔥 Mirrly TG Proxy
پراکسی تلگرام بدون VPN سیستم

اگه فقط برای تلگرام دنبال یه راه ساده برای عبور از محدودیت‌های شبکه هستید، Mirrly TG Proxy یه گزینه جالبه.
این برنامه برای اندروید، ترافیک تلگرام رو از طریق پراکسی محلی و Cloudflare عبور می‌ده و برخلاف VPNهای معمولی، کل ترافیک گوشی رو تونل نمی‌کنه؛ یعنی برنامه‌های دیگه تحت تأثیر قرار نمی‌گیرن.
🔹 پشتیبانی از MTProto و SOCKS5
🔹 مناسب برای چت، کانال، ارسال و دریافت فایل
🔹 پشتیبانی از تماس صوتی و تصویری
🔹 بدون نیاز به روت و بدون استفاده از VPN سیستم
🔹 هسته شبکه مبتنی بر Rust
🔹 امکان استفاده از Cloudflare Worker شخصی
🔹 متن‌باز و منتشرشده تحت مجوز GPLv3
📌 آخرین نسخه: v1.1.8.3
⬇️ دانلود از GitHub:
https://github.com/joycecurcirt539-dot/Mirrly-TG-Proxy/releases/tag/v1.1.8.3

🚀 معرفی ابزار DNS Benchmark Pro

سریع‌ترین DNS را با عدد پیدا کن، نه با حدس! 📊

 🔍 این ابزار چیست؟

یک ابزار متن‌باز و رایگان برای مقایسه دقیق DNS سرورها روی سه پروتکل UDP، DoH و DoT با امتیازدهی شفاف ۰ تا ۱۰۰، تشخیص هایجک و مانیتورینگ دائمی.

🔗 لینک پروژه: github.com/Alvandcode/dns-benchmark-pro

 🎯 به درد چه کسانی می‌خورد؟

| 👤 کاربر | چرا به این ابزار نیاز دارد؟ |
| --- | --- |
| 🇮🇷 کاربران ایرانی | تست شکان، الکترو، 403 و عمومی‌ها با تفکیک دامنه داخلی/خارجی |
| 🖥️ ادمین‌های شبکه | انتخاب DNS شرکت با داده واقعی + مانیتورینگ ۲۴/۷ |
| 👨‍💻 توسعه‌دهندگان | مقایسه چندرانه با فاصله اطمینان ۹۵٪ و گزارش HTML |
| 🎓 دانشجویان شبکه | یادگیری DNS واقعی با کد تمیز و تست‌شده |
| 🛡️ فعالان حریم خصوصی | تشخیص DNS hijacking و شنود |

 ⚡ شروع سریع (۳ دستور)

# ۱. نصب
pip install -r requirements.txt

# ۲. تست ساده ۳ DNS معروف
python main.py

# ۳. تست حرفه‌ای با پریست ایران
python main.py --preset ir --queries 20 --seed 42

 ✨ قابلیت‌های کلیدی

🔀 ۳ پروتکل: UDP + DoH + DoT

🏆 امتیاز ۰-۱۰۰ با گرید A+ تا F

🕵️ تشخیص هایجک خودکار (RFC 2606)

🇮🇷 پریست ایران: شکان، الکترو، 403 + تفکیک داخلی/خارجی

📈 مانیتورینگ: SQLite + نمودار روند

📄 گزارش: CSV، JSON، HTML

🛡️ امنیت: NXDOMAIN موفق حساب نمی‌شود

 📊 نمونه خروجی

COMPARISON (3 runs, 95% CI)
1.  1.1.1.1  score=99.75±0.11  grade=A+ avg=0.95ms loss=0.0% hijack=clean
2.  8.8.8.8  score=94.47±10.44 grade=A  avg=12.86ms loss=0.0% hijack=clean

 💡 چرا این ابزار متفاوت است؟

✅ صادقانه: فقط NOERROR موفق است، loss=100% → امتیاز ۰

✅ شفاف: فرمول امتیاز مستند و قابل بازتولید

✅ ایرانی: پریست اختصاصی با دامنه‌های داخلی/خارجی

✅ تست‌شده: ۷۰ تست واقعی با mock

✅ رایگان: MIT License

 📢 برای چه کسانی مناسب نیست؟

❌ کسانی که فقط می‌خواهند «اینترنت کار کند»

❌ کسانی که GUI می‌خواهند (فقط CLI)

❌ کسانی که MX/TXT نیاز دارند (فقط A/AAAA)

 🌟 حمایت از پروژه

اگر این ابزار به تو کمک کرد:

- 📣 با دوستانت به اشتراک بگذار
