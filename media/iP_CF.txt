⚙️ ساخت پروفایل و اتصال

🌐 برای راه‌اندازی TunnelForge، وارد وب‌سایت VPN Gate شوید.

📋 از بین سرورها، فقط IP عددی سرور را کپی کنید.

✅ همین! برای راه‌اندازی TunnelForge تنها چیزی که نیاز دارید همین IP است.

1. وارد بخش Profile شوید و روی مثبت + سپس  Create New Profile بزنید.

2. در قسمت Name یک نام دلخواه برای پروفایل انتخاب کنید.

3. آی‌پی‌ای که از سایت VPN Gate کپی کرده‌اید، در قسمت Server وارد کنید.

4. در بخش‌های زیر، مقدار vpn را وارد کنید:
   
   - Username: "vpn"
   - Password: "vpn"
   - IPsec PSK: "vpn"

5. به صفحه اصلی برگردید و روی Connect بزنید. 🔗

📌 اگر اطلاعات را درست وارد کرده باشید، TunnelForge باید تلاش کند اتصال L2TP را برقرار کند.

🛡️ Adblock داخلی NekoBox+
 جایگزین متن‌باز AdGuard

NekoBox+ حالا یک Adblock داخلی دارد که مستقیماً داخل هسته برنامه و "sing-box-plus" اجرا می‌شود و برای مسدود کردن تبلیغات الزاماً به AdGuard نیاز ندارید.

🔹 استفاده از Brave adblock-rust برای پردازش قوانین
🔹 سازگاری با فیلترهای uBlock Origin
🔹 فیلتر تبلیغات در DNS، HTTP، HTTPS و QUIC
🔹 پشتیبانی از CNAME Uncloaking
🔹 امکان فیلتر کردن برنامه‌ها به‌صورت جداگانه

📱 Included apps؛ فیلتر تبلیغات یک برنامه خاص

یکی از قابلیت‌های کاربردی NekoBox+ اینه که لازم نیست کل گوشی رو زیر فیلتر ببرید.

مثلاً اگر یک بازی یا اپلیکیشن تبلیغات درون‌برنامه‌ای دارد، می‌توانید همان برنامه را در Included apps اضافه کنید. از آن به بعد ترافیک آن برنامه تحت فیلتر Adblock قرار می‌گیرد و درخواست‌های مربوط به دامنه‌های تبلیغاتی، در صورت وجود قانون مناسب، مسدود می‌شوند.

⚠️ البته حذف همه تبلیغات تضمین‌شده نیست؛ اگر تبلیغ از همان سرور اصلی برنامه ارائه شود یا برنامه از روش‌هایی مثل Certificate Pinning استفاده کند، ممکن است تبلیغ همچنان نمایش داده شود یا برنامه با فیلتر HTTPS مشکل پیدا کند.

🔐 HTTPS Filtering

برای مسدود کردن تبلیغات داخل صفحات HTTPS، NekoBox+ باید ترافیک را رهگیری و رمزگشایی کند؛ بنابراین نیاز به نصب CA Certificate دارد.

در این حالت محتوای ترافیک برنامه‌های انتخاب‌شده قابل مشاهده است؛ پس بهتر است فقط برای برنامه‌هایی که واقعاً نیاز دارید فعالش کنید.

⚠️ System-wide mode را بی‌دلیل فعال نکنید.
این گزینه Adblock را روی تمام برنامه‌های گوشی اعمال می‌کند و ممکن است باعث اختلال در بعضی اپ‌ها شود.

⚡ همچنین گزینه Use Cronet طبق توضیحات خود برنامه ممکن است ناپایدار باشد و فقط در صورت نیاز باید فعال شود.

📌 پیشنهاد تنظیمات:
