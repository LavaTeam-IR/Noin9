🚀 AetherST Tunnel
 حالا برای ویندوز هم منتشر شد!
اگه دنبال یه کلاینت جدید برای دور زدن فیلترینگ و محدودیت‌های شبکه هستید، AetherST Tunnel حالا علاوه بر اندروید، رسماً برای ویندوز هم منتشر شده.
📱 Android: نسخه 1.5.0

🖥️ Windows: نسخه 1.0.0 — اولین نسخه عمومی
🛡️ تمرکز اصلی پروژه روی اتصال پایدار در شبکه‌های محدود و مقابله با DPI و شناسایی پروتکل‌هاست.
⚡ از چند روش اتصال مختلف پشتیبانی می‌کنه:
• MASQUE روی HTTP/3 و HTTP/2

• WireGuard

• Gool (WG-in-WG)
یعنی قرار دادن یک تونل WireGuard داخل WireGuard دیگه

• Cloudflare Zero Trust
🔍 یه قابلیت جالب دیگه هم اسکن هوشمند Gateway هست که قبل از اتصال، وضعیت مسیر و Gateway رو بررسی می‌کنه.
ظاهر برنامه هم با Compose Multiplatform ساخته شده تا تجربه کاربری بین اندروید و ویندوز یکپارچه باشه.
🔓 پروژه Open Source هست و کدش روی GitHub قرار داره.
📥 دانلود برای Android و Windows

💻 سورس پروژه:
https://github.com/immaghzbad/AetherST

🚀 v2rayNG 2.3.5 منتشر شد | Pre-release
نسخه جدید v2rayNG با چند تغییر مهم و کلی بهینه‌سازی منتشر شد. 👇
🔹 مهاجرت رابط کاربری به Jetpack Compose

رابط کاربری جدیدتر و مدرن‌تر شده.
🔹 مدیریت پیشرفته‌تر Subscription
حالا موقع آپدیت سابسکریپشن می‌تونید چند عملیات رو پشت‌سرهم اجرا کنید:
• آپدیت Subscription
• تست خودکار سرورها
• حذف خودکار کانفیگ‌های خراب
• مرتب‌سازی خودکار بر اساس نتیجه تست
🔹 TCP Ping اضافه شد 📡

امکان تست پینگ TCP با کنترل حداکثر تعداد درخواست‌های همزمان.
🔹 پشتیبانی از v2rayN Share

امکان وارد کردن لینک‌های داخلی v2rayN با فرمت:
v2rayn://
🔹 HTTP Header سفارشی برای Subscription
امکان اضافه کردن Headerهای دلخواه هنگام دریافت سابسکریپشن، با فرمت JSON.
🔹 Monet Dynamic Colors 🎨

پشتیبانی از رنگ‌بندی پویا در اندروید.
🔹 رفع چندین مشکل مربوط به رابط کاربری و ذخیره فایل‌های کانفیگ دستی.
🔹 بهینه‌سازی‌ها و رفع باگ‌های مختلف.

 اندرویدتو تبدیل کن به یه دسکتاپ واقعی!

📱 صفحه گوشی رو روی کامپیوتر Mirror کنی
