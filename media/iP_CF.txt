🚀 معرفی BPB-VPN؛ یه کلاینت متن‌باز برای عبور از سانسور اینترنت
اگه دنبال ابزارهای مختلف برای اتصال به اینترنت آزاد هستید، BPB-VPN یه پروژه متن‌باز برای اندرویده که چند روش مختلف رو برای دور زدن محدودیت‌های اینترنت در اختیار کاربر قرار می‌ده.
🔹 قابلیت‌ها:
▫️ پشتیبانی از پروکسی‌های WARP و پروتکل MASQUE
▫️ پشتیبانی از Psiphon و شبکه Tor
▫️ امکان استفاده از Cloudflare Workers شخصی
▫️ قابلیت زنجیره‌کردن پروکسی‌ها (Chain)
▫️ پشتیبانی از Xray و پروکسی VPN مبتنی بر HTTP
☁️ نکته مهم درباره Cloudflare Workers:
برای استفاده از قابلیت استقرار Worker شخصی، به حساب Cloudflare و توکن دسترسی (API Token) نیاز دارید. برای ساخت و دریافت توکن اختصاصی خودتون از لینک زیر استفاده کنید:
🔗 https://dash.cloudflare.com/profile/api-tokens

◾ برنامه FoxyVPN؛ کلاینت غیررسمی فایرفاکس VPN برای اندروید

◾ قبلا روش استفاده از فیلترشکن مرورگر فایرفاکس در ویندوز قرار داده شده بود. اکنون اگر به دنبال یک ابزار VPN برای اندروید هستید، FoxyVPN پروژه‌ای متن‌باز است که امکان اتصال به زیرساخت VPN موزیلا را بدون نیاز به خرید اشتراک از طریق این برنامه فراهم می‌کند. این ابزار با استفاده از هسته سفارشی‌سازی‌شده sing-box و پروتکل MASQUE به شبکه جهانی Fastly متصل می‌شود و از HTTP/1.1، HTTP/2 و HTTP/3 پشتیبانی می‌کند.

◾ برای استفاده از FoxyVPN به یک حساب فایرفاکس نیاز دارید.

🦊 FoxyVPN 2.0.2

بروزرسانی جدید هم اکنون در دسترس 

🔤 تغییرات جدید:
⏺ رفع خطای HTTP 406 و مشکل ورود به حساب: مشکل بلاک شدن درخواست‌های ربات توسط سیستم امنیتی Fastly هنگام ورود به حساب و دریافت توکن برطرف شده (باز هم با تشکر از Leslie).

⏺ دریافت تنظیمات به‌صورت پویا: از این به بعد برنامه هدرها (Headers)، User-Agentها و قوانین شبکه رو به‌صورت آنلاین از Vauth/FoxyConfig دریافت می‌کنه. برای اینکه در صورت از دسترس خارج شدن یک منبع، برنامه همچنان کار کنه، از چند CDN استفاده می‌کنه و در صورت نیاز سراغ GitHub Raw و jsDelivr می‌ره. تنظیمات هم به‌صورت آفلاین کش می‌شن تا بدون اینترنت هم قابل استفاده باشن.

⏺ رفع مشکل DNS از طریق DoH هنگام راه‌اندازی: سیستم اولیه DNS برنامه به نسخه رسمی DnsOverHttps از کتابخانه OkHttp با پشتیبانی HTTP/2 ارتقا پیدا کرده. این تغییر مشکلات قطع و ریست شدن اتصال به سرورهای اختصاصی DoH (مثل Yandex DoH) رو برطرف می‌کنه. همچنین IP سرورهای اولیه DNS از قبل بارگذاری می‌شن و مشکل نشت درخواست‌های DNS به‌صورت متن ساده هم برطرف شده.
