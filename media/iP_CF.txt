🦊 FoxyVPN
 استفاده از Firefox VPN روی کل دستگاه

اگه دنبال یه کلاینت متفاوت برای استفاده از Firefox VPN روی اندروید هستین، FoxyVPN یه پروژه متن‌باز و جالبه.

FoxyVPN یک کلاینت غیررسمی برای Firefox VPNـه که با اکانت Firefox وارد می‌شه و از سرویس Mozilla Guardian برای ایجاد اتصال استفاده می‌کنه.

🔹 امکانات:
• VPN سراسری برای کل دستگاه
• انتخاب چندین موقعیت/سرور
• Split Tunneling
• DNS رمزنگاری‌شده با DoH
• Private DNS به‌صورت پیش‌فرض
• زنجیره‌کردن پروکسی‌ها
• حالت Proxy-only
• بررسی IP و مسیر خروجی اتصال
• نمایش لاگ داخل برنامه
• تم روشن، تاریک و هماهنگ با سیستم

📌 نحوه استفاده:

1️⃣ اول باید یک اکانت Firefox داشته باشین. اگه ندارین، رایگان از اینجا بسازین:

https://accounts.firefox.com/signup

2️⃣ بعد APK برنامه رو از بخش Releases پروژه دانلود و نصب کنین:

https://github.com/Vauth/FoxyVPN/releases

3️⃣ داخل FoxyVPN با ایمیل و رمز همون اکانت Firefox وارد بشین.

4️⃣ یک موقعیت/سرور انتخاب کنین و روی دکمه Power بزنین تا VPN فعال بشه. 🔐
طبق توضیحات پروژه، اشتراک جداگانه‌ای برای FoxyVPN لازم نیست و برنامه از سهمیه ۵۰ گیگابایت ترافیک VPN ماهانه مربوط به اکانت Firefox استفاده می‌کنه. بعد از تمام‌شدن این سهمیه، اتصال تا ریست‌شدن سهمیه در ماه بعد متوقف می‌شه.
📱 Android 8.0 به بالا

📦 نسخه فعلی: v1.0.4
💻 متن‌باز و نوشته‌شده با Kotlin

https://github.com/Vauth/FoxyVPN

🚨 تلگرام یک مدل جدید پروکسی اضافه کرده: WEB Proxy

اگر اخیراً لینک‌هایی شبیه این دیدید:

"t.me/webproxy?..."

بدونید مربوط به قابلیت جدید WEB Proxy تلگرامه.

🔹 WEB Proxy چیه؟

به زبان ساده، تلگرام می‌خواد ترافیک پروکسی رو از مسیری عبور بده که بیشتر شبیه ترافیک معمولی وب و HTTPS باشه.

در این روش از WebSocket امن (WSS) استفاده می‌شه تا ارتباط بین کاربر و پروکسی ظاهر عادی‌تری داشته باشه.

یعنی به‌جای اینکه ارتباط پروکسی کاملاً مشخص و قابل تشخیص باشه، مسیر ارتباط تقریباً این شکلیه:

📱 تلگرام
⬇️
🌐 HTTPS / WebSocket
⬇️
🔐 WEB Proxy
⬇️
✈️ سرور تلگرام

🎯 هدف اصلی چیه؟

سیستم‌های فیلترینگ و DPI فقط به آدرس سرور نگاه نمی‌کنن و می‌تونن نوع ترافیک رو هم بررسی کنن. WEB Proxy تلاش می‌کنه تشخیص اینکه این ارتباط مربوط به پروکسی تلگرامه رو سخت‌تر کنه.
