1/ Claude Code Router
با تمام شدن لیمیت یک مدل، بصورت خودکار به مدل دیگری سوییچ میکنه تا روند کار متوقف نشه.

2/ Caveman
پاسخ‌های اضافی رو حذف میکنه و با حفظ نتیجه، مصرف توکن رو کاهش میده.

3/ Ponytail
از ساختار پروژه یک گراف می‌سازه تا به‌جای بررسی مکرر فایل‌ها، فقط بخش‌های مرتبط رو پیدا کنه.

4/ Agent Skills
به Claude کمک می‌کنه مراحل برنامه‌ریزی، تست، بازبینی و انتشار کد رو منظم‌تر دنبال کنه.

5/ Claude-mem
برای Claude Code حافظه بین جلسات ایجاد می‌کنه تا اطلاعات و جزئیات کارهای قبلی رو به خاطر بسپاره.
